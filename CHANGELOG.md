# Changelog

## 0.0.1

Initial release.

- DeepSeek Harness chat runtime embedded in a native VS Code Activity Bar view.
- Auto-start: clones and builds a managed `deepseek-harness` checkout on first use, with a one-time setup progress notification and a loading overlay until the runtime is ready.
- Local JSON-RPC runtime, streaming sessions, editor context, cancellation, approvals, and user questions.
- Whale mascot icon and branding throughout (activity bar, header, hero, README).
- Custom in-panel dropdown menus for model/effort/permission (no more OS-level popups escaping the panel).
- Markdown rendering for bold, italic, inline code, and bullet/numbered lists in chat messages.
- Composer centers with the hero on empty sessions; stays docked to the bottom once a conversation starts.
